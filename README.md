# WJY · Camera Tuning

基于个人简历制作的静态个人网站，适合直接部署到 GitHub Pages。

## 本地预览

```powershell
python -m http.server 8000
```

访问 `http://localhost:8000`。

## 部署

仓库的 `main` 分支可以直接通过 GitHub Pages 发布。页面不需要构建步骤，保持 `index.html`、`styles.css`、`script.js` 和 `favicon.svg` 位于仓库根目录即可。

## 页面能力

- 响应式布局与移动端导航
- 滚动进入动画与当前章节高亮
- 一键复制邮箱
- 打印 / 另存为 PDF 的简历样式
